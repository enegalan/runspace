# Keyboard shortcuts

Runspace uses standard macOS shortcuts. On Windows/Linux, use **Ctrl** instead of **Cmd**.

| Shortcut | Action |
|----------|--------|
| `Cmd+Enter` | Run |
| `Cmd+.` | Stop |
| `Cmd+S` | Save file |
| `Cmd+N` | New workspace |
| `Cmd+W` | Close tab |
| `Cmd+,` | Settings |

Shortcuts are also available from the app menu: **Run** and **Help**.

Custom shortcut remapping is planned for a future release.

# Keyboard shortcuts

Runspace uses standard macOS shortcuts. On Windows/Linux, use **Ctrl** instead of **Cmd**.

| Shortcut | Action |
|----------|--------|
| `Cmd+Enter` | Run |
| `Cmd+.` | Stop |
| `Cmd+S` | Save file |
| `Cmd+N` | New file |
| `Cmd+Shift+N` | New folder |
| `Cmd+Shift+T` | New terminal |
| `Cmd+B` | Toggle sidebar |
| `Cmd+J` | Toggle output panel |
| `Cmd+,` | Settings |
| `Cmd+W` | Close window |

Shortcuts are also available from the app menu: **Runspace**, **File**, **View**, **Run**, and **Terminal**.

Custom shortcut remapping is planned for a future release.

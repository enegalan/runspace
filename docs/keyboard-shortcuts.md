# Keyboard shortcuts

| Shortcut      | Action              |
|---------------|---------------------|
| `Cmd+Enter`   | Run                 |
| `Cmd+.`       | Stop                |
| `Cmd+S`       | Save file           |
| `Cmd+N`       | New file            |
| `Cmd+Shift+N` | New folder          |
| `Cmd+Shift+T` | New terminal        |
| `Cmd+B`       | Toggle sidebar      |
| `Cmd+J`       | Toggle output panel |
| `Cmd+,`       | Settings            |
| `Cmd+W`       | Close window        |

Customize shortcuts in **Settings → General → Keyboard shortcuts**. Click a shortcut field and press the new key combination (Cmd/Ctrl required). Use **Reset to defaults** to restore the built-in bindings.
